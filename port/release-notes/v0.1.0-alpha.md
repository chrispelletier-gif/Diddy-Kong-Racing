The first public build of Diddy Kong Racing for Nintendo 3DS: an unofficial, native port built from the community
decompilation of the N64 game. **It's an early alpha and still a work in progress.**

**No game files are included.** You need your own Diddy Kong Racing ROM, **US version 1.0** (SHA1
`0cb115d8716dbbc2922fda38e533b9fe63bb9670`).

## Before you install

- **Tested on the New 3DS family only.** It hasn't been tried on an original 3DS, 3DS XL or 2DS yet; they have a
  slower processor and less memory, so the game may run slowly or not start. Reports either way are welcome.
- **Only the US 1.0 ROM works for now.** Other versions will follow; the game tells you if yours is different.
- Adventure mode hasn't been played through end to end yet. Back up your saves (Settings > Saves) before trying a
  new build.

## Installing

1. Copy your ROM to `sdmc:/3ds/dkr/baserom.z64`.
2. Either copy `dkr.3dsx` to `sdmc:/3ds/` and start it from the Homebrew Launcher, or install `dkr.cia` with FBI to
   get a HOME menu icon.
3. For sound, the DSP firmware dump `sdmc:/3ds/dspfirm.cdc` is needed (made with DSP1), as for other homebrew.

`SHA256SUMS.txt` has the files' checksums. The [README](https://github.com/chrispelletier-gif/Diddy-Kong-Racing-3DS#readme) has the controls, settings and setup details.

## What's in it

- Runs at 30 fps (60 fps is an option), with 4x anti-aliasing, widescreen, the sharper 800-pixel mode and stereo 3D.
- A race HUD on the bottom screen (standings, map, item, lap times), or the N64's HUD on top.
- A modern chase camera (the original is an option), remappable controls and circle pad tuning.
- Saves compatible with N64 emulators, with backups from Settings > Saves.
- One player only.

## Reporting a problem

If the game crashes, it saves `last_crash.txt` and `last_log.txt` in `sdmc:/3ds/dkr/` the next time it starts.
Please open an issue saying what you were doing, which console you have and this version number, and attach those
files.
